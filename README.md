# 🚕 Taxi Booking Web Application

A full-stack web application for managing taxi bookings with an admin panel, user forms, and dynamic content rendering. Built using **Java**, **Spring Boot**, **Thymeleaf**, and **Bootstrap**, it includes full CRUD features, image upload, and modern frontend UI.

---

## 🌟 Features

- 📝 **Booking Management**  
  - Add bookings via frontend form  
  - Delete bookings from admin panel  
  - Form validation and user feedback with flash messages

- 💬 **Contact Form Handling**  
  - Read and delete contact inquiries from admin panel

- 🔐 **Admin Credential Management**  
  - Change username and password from the dashboard  
  - Secure credential check and update flow

- 🧩 **Service Module (New!)**  
  - Add services with image uploads using `MultipartFile`  
  - Dynamically render services with title, description, and image on the frontend

- 📦 **MVC Architecture**  
  - Clean separation of concerns with Service, Controller, and Model layers

---

## 🛠️ Tech Stack

- **Backend:** Java 17, Spring Boot 3.x, Maven  
- **Frontend:** Thymeleaf, HTML5, Bootstrap 5, jQuery  
- **Database:** H2 (for development)  
- **File Handling:** Multipart image upload and display
