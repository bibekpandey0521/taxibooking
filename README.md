# Taxi Booking System - Day 40 Update

## 🚀 Day 40 of #100DaysOfCode | Skill Shikshya

### 📖 Implemented Booking Add & Delete Features via Frontend

Today, the booking management experience has been enhanced to allow users and admins to create and delete bookings directly through the web UI. The update focuses on improving usability and providing real-time feedback.

---

## Features Added

1. **Booking Creation**
   - Integrated user-friendly booking forms with input validation.
   - Booking details are submitted and saved using Spring Boot backend.

2. **Booking Deletion**
   - Admin panel now supports deleting bookings.
   - Confirmation and redirect messages provide feedback on actions.

3. **UI Improvements**
   - Used Thymeleaf templating with Bootstrap to render dynamic content smoothly.
   - Better UI flow and responsive layout for booking management.

4. **Feedback & Redirects**
   - Added success/failure messages on booking add/delete actions.
   - Improved user experience with clear notifications.

---

## Tech Stack

- **Java**
- **Spring Boot**
- **Thymeleaf**
- **Bootstrap**
- **Maven**

---

## Project Overview

A web-based Taxi Booking System to manage taxi reservations, implemented with a Java Spring Boot backend and Thymeleaf front end. This update enhances the frontend interaction for booking management.
