# 🚖 Taxi Booking System – Spring Boot Project

A web-based taxi booking platform built using **Spring Boot**, **Thymeleaf**, and **Spring Data JPA**, with planned integration of **Spring Security**.

---

## 🌟 Features

- ✅ Contact Form with form validation
- ✅ Booking Form with custom validations (e.g. date, phone number)
- ✅ Layered architecture (Controller → Service → Repository)
- ✅ DAO methods for data persistence
- 🚧 User authentication with Spring Security (Coming Soon)

---

## 🔧 Tech Stack

- Java 17+
- Spring Boot
- Thymeleaf
- Spring MVC
- Spring Data JPA (Hibernate)
- Maven
